# POS Servis – aktualizace Android

Tento veřejný repozitář obsahuje **pouze instalační APK** aplikace POS Servis. Zdrojový projekt a uživatelská data nejsou veřejná.

## Stáhnout aplikaci

**[Nejnovější ověřené vydání POS Servis](https://github.com/xheckop/POS-SERVIS-DOWNLOAD/releases/latest)**

Po zveřejnění první aktualizace bude k dispozici také stálý přímý odkaz:

[POS-Servis-AKTUALIZACE.apk](https://github.com/xheckop/POS-SERVIS-DOWNLOAD/releases/download/latest/POS-Servis-AKTUALIZACE.apk)

Instalujte přímo přes stávající aplikaci; před instalací ji neodinstalovávejte, aby zůstala zachována místní data.

Každý instalační soubor je nejprve automaticky sestaven a ověřen pomocí oficiálního Android SDK v soukromém zdrojovém projektu. Vydání obsahuje kontrolní součet SHA-256.

> Novou verzi vydává automatický proces v soukromém repozitáři `xheckop/POS-SERVIS-ANDROID`. Tento repozitář je pouze veřejné distribuční místo.
